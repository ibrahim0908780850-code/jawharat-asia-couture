# JAWAHARAH ASIA — جوهرة آسيا لتصميم الأزياء

واجهة موقع عربية RTL لعلامة جوهرة آسيا لتصميم وتفصيل فساتين الزفاف والسهرة في الرياض.

## التقنيات

- React 19 + Vite
- TypeScript
- Tailwind CSS 4
- Wouter
- Lucide React

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

## الوسائط

توجد النسخ الأصلية من صور وفيديوهات الموقع داخل مجلد [`media/`](./media). تستخدم نسخة WebDev المنشورة روابط التخزين الخاصة بها لضمان توافق النشر مع بيئة WebDev.
